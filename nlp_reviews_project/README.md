# Restaurant Reviews NLP Project

Problem: Analyze restaurant review text to compare linguistic differences between 1-star and 5-star reviews, extract pros/cons, track trends over time, and build an interactive dashboard.

Contents:
- `data_loader.py` : functions to load and clean raw CSV
- `preprocessing.py` : text cleaning + spaCy pipeline (to be implemented)
- `features.py` : linguistic feature extraction (to be implemented)
- `aspect_extraction.py` : n-grams / noun-phrase / topic modeling helpers
- `streamlit_app.py` : Streamlit dashboard (skeleton)
- `notebooks/` : analysis notebooks
- `data/cleaned_reviews.csv` : cleaned dataset output (generated by scripts)

How to run (quick):
1. Create virtualenv and install `pip install -r requirements.txt`
2. Run `python nlp_reviews_project/data_loader.py --input "../Restaurant reviews.csv" --output data/cleaned_reviews.csv`
3. Start dashboard: `streamlit run nlp_reviews_project/streamlit_app.py`

Notes:
- The repository will include modular scripts and notebooks for each analysis step.
- Next steps: implement preprocessing, feature engineering, topic modeling and dashboard visuals.

## Key insights

- Sentiment is the strongest separator between 1-star and 5-star reviews: the precomputed VADER compound score shows a very large effect (mean compound for 1-star reviews is strongly negative while 5-star reviews are strongly positive). This is the clearest single signal distinguishing the classes.
- Part-of-speech patterns differ by rating: adjectival and verbal usage ratios show measurable differences between 1-star and 5-star reviews (useful as linguistic features for classification or interpretation).
- Length and readability show smaller but statistically significant differences: 1-star reviews tend to be slightly longer on average and have distinct readability scores compared with 5-star reviews.
- Topic/aspect extraction (BERTopic sample run) surfaces coherent candidate "pros" and "cons" topics and per-topic average sentiment; this enables a topic-level pros/cons explorer in the dashboard. A sample BERTopic output is saved as `data/bertopic_output_sample_topic_info.csv` and `data/bertopic_output_sample_assignments.csv`.

## Limitations

- BERTopic was run on a sample (to speed development). Full-dataset topic extraction will take longer and may change topic boundaries and sizes — manual label-cleanup is recommended before publishing insights.
- Sentiment scoring uses VADER (lexicon-based) which performs well on short, informal English but may mis-estimate sentiment for sarcasm, negation in complex sentences, or non-English reviews.
- The current pipeline assumes English-language reviews and basic preprocessing; non-English text, heavy misspellings, or domain-specific jargon may reduce extraction quality.
- Some optional dependencies (native wheels such as `floret`) require a C++ build toolchain on Windows to install; see `requirements.txt` and local setup instructions in this repo.
- Topic labels and aspect groupings are automatically generated and may require human review to convert into final "Pros" and "Cons" for reporting.
- Temporal analyses depend on reliable `time` metadata in source rows; missing or incorrectly formatted timestamps will reduce coverage for trend analyses.

## Reproducible environment (pinned)

Create a conda environment that matches the development environment exactly using the pinned YAML included in the repo:

```powershell
conda env create -f nlp_reviews_project/environment-pinned.yml
conda activate nlp-reviews-pinned
# download spaCy model
python -m spacy download en_core_web_sm
# run the Streamlit dashboard
streamlit run nlp_reviews_project/streamlit_app.py
```

If you prefer a lighter environment (using prebuilt conda packages where possible) use:

```powershell
conda env create -f nlp_reviews_project/conda-environment.yml
conda activate nlp-reviews
python -m spacy download en_core_web_sm
streamlit run nlp_reviews_project/streamlit_app.py
```

Notes:
- The pinned environment installs exact package versions (large downloads). Expect longer setup times.
- If a pip-installed package still fails to build on Windows (native extensions like `floret`), prefer the `conda-environment.yml` or install the Build Tools shown in the repo notes.
